## 模块详情

### M1: 项目骨架与数据层（P0）
**内容**：FastAPI 项目结构（`app/` 分层：models/schemas/services/routers）、SQLAlchemy 数据模型（todos 表）、SQLite 初始化与建表、配置管理（端口、数据库路径）。
**交付物**：可启动的 FastAPI 骨架 + 数据库建表 + 单元测试（模型层）。
**验收**：`uvicorn` 启动无报错，pytest 通过。

### M2: 待办 CRUD API（P0）
**内容**：POST/GET/PUT/DELETE /api/todos、PATCH /api/todos/{id}/complete；Pydantic Schema 校验（标题必填、优先级枚举、标签数组）；输入校验错误返回 422。
**交付物**：完整 CRUD 端点 + pytest 接口测试。
**依赖**：M1。
**验收**：接口测试覆盖所有 CRUD 路径（含异常路径）。

### M3: 视图与筛选 API（P0）
**内容**：GET /api/todos 支持 view 参数（today/week/overdue/all）与 tag、priority、status 筛选参数；排序规则（优先级降序 + 到期时间升序）；视图统计接口（当前视图的待办/已完成/逾期计数）。
**交付物**：筛选查询逻辑 + 接口测试。
**依赖**：M2。
**验收**：各视图边界正确（今日 00:00-23:59、本周周一至周日、逾期不含已完成）。

### M4: 前端基础框架与页面骨架（P0）
**内容**：Vite + Vue3 + Element Plus 项目初始化；整体布局（左侧栏 + 主区域 + 底部状态栏）；API 封装（axios）；路由/状态管理按需最小化（仅用组合式函数，不引 Pinia/Router 除非必要）。
**交付物**：可运行的页面骨架 + API 层封装。
**验收**：`npm run dev` 启动正常，布局三区域完整。

### M5: 新建/编辑待办（前端）（P0）
**内容**：新建按钮 + 对话框表单（标题/内容/优先级/标签/到期时间/提醒时间快捷选项）；编辑复用同一表单并回填；标签输入支持新建；表单校验与错误提示。
**交付物**：完整表单组件 + 联调通过。
**依赖**：M2（API）、M4。
**验收**：US-001、US-005 验收标准全部满足。

### M6: 待办列表与多视图（前端）（P0）
**内容**：待办卡片组件（优先级色块/标签/到期时间/勾选框/编辑删除入口）；四个视图切换；标签筛选；列表排序展示；空状态提示。
**交付物**：列表页完整功能。
**依赖**：M3、M4。
**验收**：US-002、US-003 验收标准全部满足。

### M7: 完成操作与状态栏（前端）（P0）
**内容**：勾选切换完成状态（调 PATCH 接口）；已完成样式（删除线）；底部状态栏实时统计（当前视图计数）。
**交付物**：完成交互 + 状态栏。
**依赖**：M6。
**验收**：US-004、US-008 验收标准全部满足。

### M8: 提醒调度与系统通知（P0）
**内容**：APScheduler 后台任务（30 秒周期）扫描 remind_at ≤ now 且未触发的待办；winotify 弹 Windows Toast；已触发标记持久化（reminded 字段或触发记录）；调度逻辑单元测试（mock 时间）。
**交付物**：提醒调度模块 + 测试。
**依赖**：M2。
**验收**：US-006 验收标准全部满足；测试用 mock 时钟验证触发与防重复。

### M9: Electron 桌面集成（P0）
**内容**：Electron 主进程；启动时 spawn 后端进程（开发模式 spawn uvicorn，生产模式 spawn 打包后的 exe）；轮询 /api/health 判就绪后加载页面；窗口最小化保持运行；关闭窗口时 kill 后端子进程；端口动态获取（后端写端口到环境/文件，Electron 读取）。
**交付物**：Electron 壳工程 + 开发模式可直接跑通。
**依赖**：M4（前端页面存在）。
**验收**：US-007 中窗口行为相关标准满足（开发模式验证）。

### M10: EXE 打包链路（P0）
**内容**：Vue build → FastAPI 托管静态文件 → PyInstaller 打包后端 → electron-builder 打包整体（portable / nsis 二选一，先 portable 验证）；打包脚本一键化。
**交付物**：可双击运行的 EXE + 打包脚本。
**依赖**：M8、M9。
**验收**：双击 EXE 启动到可交互 ≤ 5 秒；关闭无残留进程；最小化时提醒正常。

### M11: 联调测试与交付（P0）
**内容**：端到端流程验证（新建→提醒→完成→视图统计）；打包产物在干净环境冒烟测试；交接文档（运行说明、打包说明、目录结构）。
**交付物**：验收报告 + docs/handoff.md。
**依赖**：M10。
**验收**：PRD 全部验收标准通过。
