# PRD：待办助手（To-do Reminder）

## 1. 介绍 / 概述

一个纯个人使用的 Windows 桌面待办管理工具。用户可以每日新建待办事项，设置优先级与标签，按视图查看任务；待办到期时通过 Windows 系统通知弹出提醒。最终交付形态为 EXE 桌面应用，双击即可使用，无需手动启动前后端。

**解决的核心问题**：日常工作中待办事项分散、容易遗忘，需要一个轻量的、能主动提醒的本地待办管理工具。

## 2. 目标

- 用户可以在 10 秒内完成一条待办的新建（标题 + 到期时间）
- 到期提醒通过 Windows 原生 Toast 通知弹出，不依赖应用窗口是否打开
- 支持今日/本周/已逾期/全部四个视图快速切换
- 交付单可执行 EXE，双击启动，窗口可最小化，关闭即退出
- 应用启动到可交互 ≤ 5 秒

## 4. 功能需求

- FR-1: 系统必须支持待办的创建、查询、编辑、删除、完成标记（CRUD）
- FR-2: 待办字段必须包含：标题（必填）、内容、优先级（高/中/低，默认中）、标签（JSON 数组）、到期时间、提醒时间、状态（pending/completed）、完成时间
- FR-3: 系统必须提供视图筛选：today（今日）、week（本周）、overdue（已逾期）、all（全部）
- FR-4: 系统必须支持按标签筛选待办
- FR-5: 后端调度器必须周期性（30 秒）扫描到期提醒并触发 Windows Toast 通知，每条提醒仅触发一次
- FR-6: 系统必须提供 /api/health 健康检查接口供 Electron 判断后端就绪
- FR-7: 应用必须打包为 Windows EXE，双击启动，关闭窗口退出并清理子进程
- FR-8: 后端监听端口被占用时必须自动选择可用端口并通知 Electron
- FR-9: 待办列表必须按优先级降序 + 到期时间升序排列

## 5. 非目标（Out of Scope）

- 不做完成统计图表
- 不做重复待办（每日/每周循环）
- 不做多用户支持（纯个人单用户）
- 不做云同步 / 手机端
- 不做开机自启动（后续可选）
- 不做待办搜索功能
- 不做子任务 / 待办依赖

## 6. 设计考虑

- 左侧栏：视图切换（今日/本周/已逾期/全部）+ 标签筛选列表
- 主区域：待办卡片列表，优先级色块（🔴高/🟡中/⚪低）+ 标签 + 到期时间
- 底部状态栏：待办数/已完成数/逾期数
- 新建/编辑弹窗：标题/内容/优先级/标签/到期时间/提醒时间
- 界面风格：Element Plus 组件库，简洁清爽

## 7. 技术考虑

- 后端：Python 3.14 + FastAPI + SQLAlchemy + SQLite + APScheduler + winotify
- 前端：Vue 3 + Element Plus + Vite
- 桌面：Electron（主进程管理后端子进程 + BrowserWindow）
- 打包：PyInstaller（后端）+ electron-builder（整体）
- 端口策略：默认 8000，被占用时自动探测可用端口（如通过环境变量/启动参数传递给 Electron）
- 中文路径兼容：Python 启动需 `-X utf8`
- 用户真实 Python：D:\developTools\python\python3.14.5
